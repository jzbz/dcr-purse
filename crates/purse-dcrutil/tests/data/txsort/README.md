# txsort test transactions

The `.hex` files are dcrd's `dcrutil/v4/txsort/testdata` at v4.0.3, the
version dcrwallet links, copied unchanged. They are used by
`tests/upstream_txsort.rs` (the port of `txsort_test.go`) and are part of the
differential and frozen corpora.
