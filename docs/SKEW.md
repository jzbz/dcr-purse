# Version skew ledger

dcrwallet links tagged releases of dcrd's modules; dcroxide ports dcrd master. This ledger records, per module, what each side carries, how the two differ, who could observe the difference, and how dcr-purse handles it ([ADR-0009](adr/0009-version-skew-against-dcroxide.md), decision D7). It is redone by the change that moves any pin below, from a dcrd clone and the Go module cache (ADR-0009 item 2). The `crates/purse-testutil` test `skew` and the Go test `tools/oracle/internal/deps` hold the header and the dcrwallet column to the pins (item 3).

- dcrwallet: `54b85b336077587eaf20112dc695355ce06fc76e`
- dcroxide rev: `48f5b5ec1f122ee89170e939ead53e32cd0ac8d9`
- dcroxide's dcrd pin: `46e9df48109a167c4a1b5e6fafc4a6926498e7c6`
- Reference Go, dcr-purse: `go1.27.4`
- Reference Go, dcroxide: `go1.27.3`

Columns. **dcrwallet**: the version `tools/oracle/dcrwallet.go.mod` (dcrwallet's `go.mod` at the pin) requires; in the Go toolchain row, dcr-purse's reference Go, which builds the oracle (dcrwallet's `go.mod` names only `go 1.26.0`, with no `toolchain` line). **dcroxide**: the directory dcroxide ports at its dcrd pin, or the release it ports where dcrd links one, and the crate. **Diff**: run in a dcrd clone (nested modules excluded), or against the Go module cache (`$GOMODCACHE` is `go env GOMODCACHE`). **Delta**: `none`, `comments or tests only`, or `code`, from reading the whole diff; a change to `go.mod`'s module path is code. **Observable**: by whom, as the brief's §3 surfaces (W1–W7). **Disposition**: `reuse as is`, `parameterise in dcroxide`, `wallet-side constant or shim`, `own port`, or `not linked`. **Differential**: the dcr-purse test that compares the wallet path with dcrwallet's oracle, or `no differential yet`.

- Pins: dcrwallet's `go.mod` at `54b85b33` copied verbatim to `tools/oracle/dcrwallet.go.mod` (its `h1:` hash equals `tools/oracle/go.sum:4`); dcroxide `5c6742f` from the root `Cargo.toml`; its dcrd pin `46e9df48` read from dcroxide's `docs/PARITY.md`, the pseudo-versions in its `tools/oracle/go.mod` and `DCRD_PARITY_COMMIT` in `dcroxide-testutil`; reference Go from `REFERENCE_GO` and both CI workflows' `GO_VERSION`.
